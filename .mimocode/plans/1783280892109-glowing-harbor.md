# Candidate 3: Config-Nix Drift Check

## Problem

7 config-nix files in `linux-cachyos/config-nix/` are checked into git as IFD cache. Generated by `update.nix`, consumed by `packages-for.nix:103`. Changing `config-vars` without running `update.nix` causes silent drift. No CI catches it.

## Current State

- `check.yml`: builds `configfile` per variant, never verifies config-nix
- `update.nix` lines 129-137: generates config-nix via `nix build ".#linux_cachyos${flv}.kconfigToNix"`
- 7 config-nix files: gcc, lto, znver4, server, hardened, rc, lts
- `check.yml` matrix: only 6 variants (missing lto-znver4)

## Plan

### Edit: `.github/workflows/check.yml`

1. Add `lto-znver4` to existing `check` job matrix
2. Add new `config-nix-check` job with full 7-variant matrix using `include` for variant-to-file mapping
3. Each matrix entry builds `kconfigToNix` output, diffs against checked-in file

```yaml
config-nix-check:
  strategy:
    matrix:
      include:
        - variant: gcc
          config_file: cachyos-gcc.x86_64-linux.nix
        - variant: lto
          config_file: cachyos-lto.x86_64-linux.nix
        - variant: lto-znver4
          config_file: cachyos-znver4.x86_64-linux.nix
        - variant: server
          config_file: cachyos-server.x86_64-linux.nix
        - variant: hardened
          config_file: cachyos-hardened.x86_64-linux.nix
        - variant: rc
          config_file: cachyos-rc.x86_64-linux.nix
        - variant: lts
          config_file: cachyos-lts.x86_64-linux.nix
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v4
    - uses: cachix/install-nix-action@v30
    - name: Build kconfigToNix
      run: nix build .#linux_cachyos-${{ matrix.variant }}.kconfigToNix -L --impure
    - name: Diff against checked-in config-nix
      run: diff <(cat result) linux-cachyos/config-nix/${{ matrix.config_file }}
```

## Verification

```bash
for v in gcc lto lto-znver4 server hardened rc lts; do
  nix build ".#linux_cachyos-${v}.kconfigToNix" --impure
  f="cachyos-${v}.x86_64-linux.nix"
  [ "$v" = "lto-znver4" ] && f="cachyos-znver4.x86_64-linux.nix"
  diff result "linux-cachyos/config-nix/$f" && echo "$v: OK" || echo "$v: DRIFT"
done
```
